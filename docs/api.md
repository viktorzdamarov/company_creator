# API и правила работы

Интерактивная документация (Swagger) доступна на запущенном сервере: http://127.0.0.1:8000/docs

## Создание кампании

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/offers?q=` | поиск офферов по ID или части названия (автокомплит) |
| `POST` | `/api/campaigns` | создать кампанию: `{"name": "...", "geo": "MX,AU,RO", "offer_id": 18813}` |
| `POST` | `/api/campaigns?dry_run=true` | то же без создания: показывает, что будет отправлено в Keitaro |

Создаваемая кампания:
- **Flow 1** — фильтр «Страны принимать = GEO» → редирект на https://google.com
- **Flow 2** — весь остальной трафик → выбранный оффер (100%)
- домен, группа и источник — из `KEITARO_DEFAULT_*` в `.env`; ротация «По позиции», CPC

Ответ содержит ID кампании, tracking URL и созданные потоки. Ошибки:
`422` — неверный GEO/имя или Keitaro отклонил данные; `404` — оффер не найден; `403` — у ключа нет прав на оффер;
`409` — кампания с таким именем уже есть; `502/503/504` — проблемы с Keitaro (ключ, недоступность, таймаут).
Если поток не создался, кампания удаляется (откат). Все операции пишутся в таблицу `operation_logs`.

## Редактор

Редактор хранит локальную копию потоков и офферов в БД (таблицы `editor_*`). Все правки сначала делаются
в ней и попадают в Keitaro только после Push.

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/campaigns?q=` | список кампаний Keitaro, поиск по ID или части имени |
| `POST` | `/api/campaigns/{id}/fetch` | **Fetch streams**: загрузить потоки из Keitaro и слить с локальной копией |
| `GET` | `/api/campaigns/{id}` | локальная копия: потоки, офферы с %, статусы, Клики / Уник. / Боты (`404`, если ещё не загружена) |
| `POST` | `/api/campaigns/{id}/streams/{stream_id}/offers` | добавить оффер в черновик `{"offer_id": 18813}` |
| `DELETE` | `/api/campaigns/{id}/streams/{stream_id}/offers/{offer_id}` | удалить оффер из черновика (серый, 0%) |
| `POST` | `.../offers/{offer_id}/bring-back` | вернуть удалённый оффер |
| `PUT` | `.../offers/{offer_id}/pin` | закрепить / открепить долю `{"pinned": true}` |
| `POST` | `.../streams/{stream_id}/push` | **Push**: опубликовать поток в Keitaro |
| `POST` | `.../streams/{stream_id}/cancel` | **Cancel**: отменить неопубликованные изменения потока |

### Правила редактора (по видео заказчика)

- **Fetch streams** загружает потоки. Поток без офферов показывается просто как поток, без фильтров и редиректа.
- **Добавление и удаление** меняют только локальную копию: поток становится жёлтым («не опубликован»), в Keitaro
  ничего не уходит; доли пересчитываются сразу.
- **Статусы оффера:** `active` (в Keitaro), `new` (добавлен, не опубликован), `removing` (удалён, но ещё в Keitaro),
  `removed` (архив: удалён из Keitaro, остаётся у нас).
- **Push** отправляет офферы и доли потока, перечитывает поток из Keitaro и сверяет результат. Удалённые офферы
  уходят из Keitaro, но остаются в архиве. Нельзя опубликовать поток без офферов (`422`) или с суммой долей не 100% (`422`).
  Если поток успели изменить прямо в Keitaro после последнего Fetch, Push ничего не отправляет и отвечает `409`:
  нажмите Fetch streams (неопубликованные правки сохранятся) и повторите Push.
- **Cancel** убирает добавленные и не опубликованные офферы, отменяет удаления и возвращает доли.
- **Bring back** возвращает оффер из архива (или отменяет ещё не опубликованное удаление).
- **Повторный Fetch:** оффер, удалённый в самом Keitaro, не пропадает, а становится серым `removed`;
  неопубликованные локальные изменения сохраняются.
- **Доли:** по умолчанию поровну (100/N, остаток по 1% первым офферам: 3 → 34/33/33). Закреплённая доля не меняется,
  остальные офферы делят остаток поровну (закреплён 25% из 4 → остальные 25/25/25; один удалён → 25/38/37).
  Закреплённые доли не могут давать больше 100% или не оставлять места незакреплённым офферам (`422`, ничего не меняется).
- Офферы редактируются только в потоках с офферами (`422` для остальных); один оффер дважды в поток — `409`;
  оффер, на который у ключа нет прав, — `403`.
- Все действия пишутся в `operation_logs`.

Форматы запросов и ответов самого Keitaro: [keitaro_api_notes.md](keitaro_api_notes.md).
