# DEMO-режим

Позволяет попробовать всё приложение (создание кампаний и редактор) без настоящего Keitaro: вместо него работает
встроенная имитация с вымышленными данными. Адрес и ключ Keitaro не нужны.

Включить: в `.env` поставить `DEMO_MODE=true` и запустить как обычно. Вверху страницы появится жёлтая плашка DEMO.

- 5 вымышленных офферов (ID 9001–9005) лежат в [app/keitaro/demo_offers.json](../app/keitaro/demo_offers.json),
  их можно править;
- при первом запуске создаются кампании `demo_campaign_001` (1 оффер) и `demo_campaign_multi` (3 оффера);
  новые кампании можно создавать через форму;
- Клики / Уник. / Боты выдуманные, но стабильные;
- «Keitaro» хранит состояние в файле `DEMO_STATE_FILE` (по умолчанию `demo_state.json`).

**Начать заново:** остановить сервер, удалить `demo_state.json` и `adrobot.db`, выполнить `alembic upgrade head`,
запустить сервер.

**Сценарий редактора в браузере** (добавить → Push → Pin → Remove → Bring back → Cancel; нужны Node.js 18+ и Edge/Chrome,
демо-сервер должен быть запущен):

```bash
cd tests/e2e
npm install
ADROBOT_URL=http://127.0.0.1:8000 npm run demo
```
