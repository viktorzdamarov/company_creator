# Adrobot

Сервис для трекера Keitaro (10.3.x): создание кампаний по шаблону и редактор офферов в существующих кампаниях.

Стек: FastAPI, SQLAlchemy 2.0, Alembic, фронт на HTML + jQuery.

> Статус: этап 5 — создание кампаний, редактор офферов и веб-интерфейс готовы.

## Веб-интерфейс

После запуска (`uvicorn app.main:app --reload`) откройте http://127.0.0.1:8000:

- **New campaign** (`/create`) — форма по макету ТЗ: Name, Geo (`MX,AU,RO`), Offer с автокомплитом, кнопка Create.
  Галочка «Предпросмотр (dry run)» показывает, что будет создано, ничего не отправляя в Keitaro.
  После создания — ID, tracking URL (кнопка «копировать»), потоки и ссылка в редактор.
- **Editor** (`/edit`, `/edit/{id}`) — поиск кампании по ID или названию; потоки как в Keitaro
  (фильтры, офферы с %, Клики / Уник. / Боты, итоги); добавление оффера (автокомплит + «Добавить»)
  и удаление (×) с пересчётом процентов без перезагрузки страницы.

Фронт — Jinja2-шаблоны + jQuery 3.7.1 (`app/templates`, `app/static`), данные берутся из JSON API.

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/offers?q=` | поиск офферов по ID или части названия (автокомплит) |
| `POST` | `/api/campaigns` | создать кампанию: `{"name": "...", "geo": "MX,AU,RO", "offer_id": 18813}` |
| `POST` | `/api/campaigns?dry_run=true` | то же без создания: показывает, что будет отправлено в Keitaro |

Создаваемая кампания:
- **Flow 1** — фильтр «Страны принимать = GEO» → редирект на https://google.com
- **Flow 2** — весь остальной трафик → выбранный оффер (100%)
- домен, группа и источник — из `KEITARO_DEFAULT_*` в `.env`; ротация «По позиции», CPC

Ответ содержит ID кампании, tracking URL и созданные потоки. Ошибки:
`422` — неверный GEO/имя или Keitaro отклонил данные; `404` — оффер не найден; `409` — кампания с таким именем уже есть;
`502/503/504` — проблемы с Keitaro (ключ, недоступность, таймаут). Если поток не создался, кампания удаляется (откат).
Все операции пишутся в таблицу `operation_logs`.

### Редактор

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/campaigns?q=` | список кампаний, поиск по ID или части имени |
| `GET` | `/api/campaigns/{id}` | кампания: потоки, фильтры, офферы с %, Клики / Уник. / Боты |
| `POST` | `/api/campaigns/{id}/streams/{stream_id}/offers` | добавить оффер `{"offer_id": 18813}` |
| `DELETE` | `/api/campaigns/{id}/streams/{stream_id}/offers/{offer_id}` | удалить оффер |

Правила редактора:
- проценты всегда делятся **поровну** между офферами потока: 100/N, остаток по 1% первым офферам
  (1 → 100; 2 → 50/50; 3 → 34/33/33); пересчёт при каждом добавлении и удалении;
- офферы редактируются только в потоках с офферами; поток-редирект (→ google.com) — `422`;
- один и тот же оффер нельзя добавить дважды — `409`;
- последний оффер потока удалить нельзя — `409` (иначе трафику некуда идти);
- после сохранения поток перечитывается из Keitaro и сверяется; ответ — актуальное состояние кампании.

## Требования
- Python 3.11+
- Доступ к Keitaro и API-ключ (Keitaro → Профиль → API ключи)

## Установка

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # затем заполните KEITARO_URL и KEITARO_API_KEY
```

## Миграции

```bash
alembic upgrade head      # создать/обновить схему БД
alembic downgrade base    # откатить все миграции
```

По умолчанию используется SQLite (`adrobot.db`); для Postgres задайте `DATABASE_URL`.

## Запуск

```bash
uvicorn app.main:app --reload
```

- Healthcheck: http://127.0.0.1:8000/health
- Swagger: http://127.0.0.1:8000/docs

## Тесты

```bash
pytest
```

Проверка подключения к реальному Keitaro (только чтение, ничего не меняет):

```bash
python -m scripts.keitaro_smoke            # справочники, офферы, дефолты из .env
python -m scripts.keitaro_smoke 215521     # + потоки и статистика кампании
```

Форматы запросов/ответов Keitaro API: [docs/keitaro_api_notes.md](docs/keitaro_api_notes.md).

Браузерный smoke-тест интерфейса (нужны Node.js 18+ и Edge/Chrome; в Keitaro ничего не меняет —
создание в режиме dry-run, правки отклоняются до сохранения). Сценарий рассчитан на текущий тестовый
трекер: кампания `adrobot-test-au-1` (215534) и оффер 18813.

```bash
uvicorn app.main:app --port 8000          # в отдельном терминале
cd tests/e2e && npm install
npm test                                   # BROWSER_PATH=... для Chrome, ADROBOT_URL=... для другого адреса
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `KEITARO_URL` | адрес трекера |
| `KEITARO_API_KEY` | ключ Admin API |
| `KEITARO_DEFAULT_DOMAIN` / `_GROUP` / `_SOURCE` | домен, группа и источник для новых кампаний |
| `KEITARO_TIMEOUT` / `KEITARO_MAX_RETRIES` / `KEITARO_RETRY_BACKOFF` | таймаут запроса, число повторов при 429/5xx/сетевых ошибках, начальная пауза |
| `DATABASE_URL` | строка подключения SQLAlchemy |
| `LOG_LEVEL` | уровень логирования |
